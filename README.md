# 🚗 Driver Distraction Detection System

A real-time Driver Monitoring System built with Python, OpenCV, and MediaPipe.

The system uses a laptop camera to monitor the driver and detect:
- 😴 Drowsiness / closed eyes
- 👀 Looking left or right
- 🥱 Yawning
- 📱 Mobile phone usage
- ⚠️ Driver distraction

## ✨ Features

- Real-time webcam monitoring
- Eye-closure detection
- Yawning detection
- Gaze/distraction detection
- Mobile phone detection using YOLO
- Warning messages on screen
- Event logging
- CSV event log
- Real-time FPS display

## 🛠️ Technologies

- Python
- OpenCV
- MediaPipe
- YOLO
- NumPy
- Computer Vision
